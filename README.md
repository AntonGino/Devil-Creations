#  DevilCreations Generative AI

Welcome to the **DevilCreations AI**! This is the platform where innovation meets creativity, enabling users to explore the future of AI-driven content generation.  

---

## 🎨 Features

- **AI Image Generation**  
  Seamlessly generate stunning visuals using state-of-the-art AI models.
  
- **AI Chatbot**
  Intelligent conversations.

- **Video Generator**
  AI-powered video creations in stunning qualities.
  
- **Google Authentication**  
  Secure and user-friendly login system integrated with Google.  

- **Models**  
  Uses best open-source models for generations for best outputs.  

- **Data Management**  
  Store and manage Data to keep track of your creative experiments.  

---

## 🌐 Technologies Used

- **Frontend**: HTML, CSS, JavaScript (ES6)  
- **Backend**: Google Firebase for database and authentication  
- **AI Models**: Integration with leading open-source and proprietary generative models
